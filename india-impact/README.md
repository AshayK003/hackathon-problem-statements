# 🇮🇳 India Impact

**5 AI projects** solving India's invisible infrastructure problems — where the DPI exists but the intelligent application layer doesn't.

---

## Why This Track

India's **Digital Public Infrastructure (DPI)** — Aadhaar, UPI, DigiLocker, UMANG, BharatNet, data.gov.in — is among the most ambitious in the world. APIs exist for land records, court cases, agricultural prices, and 740+ government schemes. But the **intelligent application layer** that makes these APIs useful for ordinary citizens is almost entirely missing.

Unlike US civic tech (fragmented by state and plagued by vendor lock-in) or generic Global South problems (pre-DPI, no digital foundation), India sits in a unique sweet spot: **the plumbing is built, but nobody wrote the apps.**

Each of these problems targets a specific structural inefficiency in India's economy or governance — where the data exists, the stakeholders are quantified, the API is open, and the AI has never been applied.
